# Métricas e IA no Ecossistema de Software e de TI

O objetivo do trabalho é desenvolver e apresentar um posicionamento crítico sobre sete temas sugeridos pelo professor Leonardo Pelizzoni, cujo cada tema foi distribuido um para cada grupo da turma. 

## Tema recebido - Produtividade

### "_A IA torna os desenvolvedores melhores?_"

#### Perguntas norteadoras

- O que significa “ser produtivo” em desenvolvimento de software? Velocidade é a mesma coisa que produtividade?

- Como alguém consegue medir isso de forma confiável? por que é tão difícil?

- A sensação de estar produzindo mais é prova de que se está produzindo mais?
